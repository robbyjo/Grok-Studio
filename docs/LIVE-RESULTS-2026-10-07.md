# Authenticated acceptance, 2026-10-07

The source GUI passed the disposable-repository live suite using the selected portable Grok profile after browser OAuth sign-in. The runtime was bundled Grok 1.0.46 (2765805b9442). These are real account/model requests, not replayed ACP fixtures.

| Scenario         | Observed result                                                                                                                                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Edit and test    | Model read and edited `value.txt`, then ran a real Node assertion; tool output contained `LIVE_TEST_OK`. Git diff identified only the requested tracked file.                                                                                     |
| Approve once     | The GUI selected the runtime's exact `allow_once` option; the actual shell command created its marker.                                                                                                                                            |
| Reject           | The GUI selected `reject_once`; the marker was absent and the rejected turn terminated.                                                                                                                                                           |
| Cancel           | The real delayed command first created its start marker. GUI Stop canceled the turn; after waiting beyond its timer, no late marker existed. No pending approval remained.                                                                        |
| Restart/resume   | The app quit and restarted normally. Session ID and saved entry IDs persisted, and the model recalled a unique phrase without receiving it again.                                                                                                 |
| Model and effort | Switched from `grok-4.7` to the advertised alternative and from `high` to another advertised reasoning effort, made real requests at each setting, then restored the originals.                                                                   |
| Modes            | Unavailable: this authenticated runtime advertised no ACP modes. This is not counted as a passing mode transition.                                                                                                                                |
| MCP              | Temporarily registered a local STDIO fixture. Native doctor succeeded, then the model actually called `say_hello`. The fixture logged `tools/call` and the transcript contained `HELLO_FROM_MCP_FIXTURE`. The registration was removed afterward. |

The initial runs exposed and reproduced three issues: vendor folder-trust callbacks use `_x.ai/...` on the wire; a native permission rejection ends a turn with `cancelled`, so subsequent prompts must accept an interrupted idle connection; configuration values are strings rather than nested objects. These were repaired before the successful rerun. Regression tests exercise interrupted continuation and the real vendor callback spelling.

Local raw evidence is intentionally ignored: `.test-data/live-c6p5ty/report.json` and its screenshot. The report contains the generated repository location, actual tool entries, permission selections, session ID, configuration and final diff. Credentials are excluded from committed evidence. Run `npm run test:live` explicitly to reproduce; it sends billable real requests and needs a signed-in selected profile. `GROK_STUDIO_LIVE_HOME` selects another profile; `GROK_STUDIO_LIVE_EXE` selects a packaged/portable executable.

This source result does not certify a rebuilt portable artifact, account expiry/refresh, third-party MCP OAuth providers, a pristine Windows installation, or sustained concurrency. Second-machine testing is separate. DESKTOP's observed baseline is Windows 11 Pro, Git present, Node and Grok absent on PATH; its Windows-update reboot interrupted the initial remote attempt before transfer.
