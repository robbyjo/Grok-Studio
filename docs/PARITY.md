## Evidence boundaries

The published 0.6.3 executable predates the storage/update/review work in this source snapshot; no release was made for it. [VALIDATION.md](VALIDATION.md) distinguishes fixtures, real account requests, bounded simulated concurrency, developer-machine portability and historical versions. No percentage or exhaustive guarantee is claimed about Codex's changing feature set.

The backend exposes finite native extensions and validates owned-task IDs. Catalog snapshots exclude configured MCP header/env/setup secrets. Direct configuration editing intentionally displays the selected configuration and can contain secrets, but does not persist that text in desktop state. Account privacy changes require an explicit reviewed action. Diagnostics exclude prompt bodies, credentials and provider stderr.

Git, save, rewind and apply checks detect stale reviews; they are not cross-process filesystem locks. Hooks/tools/actions run as the current Windows user. Recoverable archive writes its Git snapshot before removing the checkout. Authentication is owned by Grok; cross-machine credential transfer is never automatic.
